# Скил: search_theory

Проверка бизнес-идеи, гипотезы или ниши на состоятельность **до** вложений времени и денег.

## Когда применять

- Есть сформулированная идея, и нужно решить, вкладываться ли
- Нужно сравнить несколько идей между собой
- Нужно понять, почему предыдущие идеи не сработали

## Что даёт

Вердикт «браться или закрыть» с обоснованием по критериям, формулировкой рычага, следующим минимальным действием для проверки и честно названным неснятым риском.

## Ключевые положения

- **Конкуренты — доказательство спроса, а не препятствие.** Пустая ниша почти всегда означает, что там не платят
- **Выбор идёт не по нише, а по рычагу.** Рычагов три: узкое качество, канал, скорость. Без хотя бы одного начинать не стоит, даже если боль настоящая
- **Описание — не действие.** Если продукт конкурента выдаёт информацию, а не решение, человек остаётся один на один с задачей и не платит
- **Процесс считают формальностью.** Ценность в «надо научиться» денег не приносит; платят за результат и за избавление от процесса
